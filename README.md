# AI-teejuht

Praktiline eestikeelne juhend, kuidas AI-st igapäevatöös rohkem kasu saada ja seda turvaliselt kasutada. Juhend lähtub Claude'ist, kuid samad põhimõtted kehtivad ka ChatGPT-s ja teistes AI-tööriistades.

**Vaata lehte:** https://lisettheinroos.github.io/AI-teejuht/

## Lehed

| Leht | Sisu |
|---|---|
| [AI-teejuht](index.html) | Põhitõed, turvaline kasutamine, hea prompt, seadistamine, automatiseerimine ja skillid |
| [AI-häkid](hakid.html) | Lühikesed nipid koos promptidega, mida saab kopeerida ja oma töö jaoks kohandada |
| [AI-ideed](edulood.html) | Ideed ja näidislood eri valdkondadest, mis näitavad, mida AI-ga teha saab |

Häkkide ja ideede lehel saab kirja panna ka oma nipid ja lood. Need salvestuvad ainult külastaja enda brauserisse ega jõua kellegi teiseni.

## Kellele

Töötajatele, meeskonnajuhtidele ja HR-ile, kes tahavad AI-d tööl kasutada või kolleegidele tutvustada. Juhend sobib kohandamiseks ka oma ettevõtte sisejuhendiks.

## Tehniliselt

Lihtne staatiline veebileht: HTML, CSS ja JavaScript, ilma ehitussammu ja serverita. Avaldatud GitHub Pagesi kaudu. Kohalikuks vaatamiseks ava `index.html` brauseris.
