# AI-teejuht

Praktiline eestikeelne juhend, kuidas AI-st igapäevatöös rohkem kasu saada ja seda turvaliselt kasutada. Juhend lähtub Claude'ist, kuid samad põhimõtted kehtivad ka ChatGPT-s ja teistes AI-tööriistades.

**Vaata lehte:** https://pilveaim.ee/

## Lehed

| Leht | Sisu |
|---|---|
| [Esileht](index.html) | Põhisõnum, kolm teekonda, lühike Minust ja lingid |
| [Juhendi sisukord](juhend/index.html) | Kõik teemad kolme peatüki kaupa |
| [1. AI põhitõed](juhend/pohitoed/index.html) | Mis on AI, otselingid, andmete valgusfoor |
| [Seadistamine](seadistamine/index.html) | Viis sammu Claude'i kohandamiseks. Lisateemad: [paketid](seadistamine/paketid/index.html) ja [Claude vs ChatGPT](seadistamine/vordlus/index.html) |
| [2. AI igapäevatöös](juhend/igapaev/index.html) | Hea prompt, projektid ja vestlused, kontroll enne saatmist, Chat või Cowork |
| [3. Automatiseerimine](juhend/automatiseeri/index.html) | Automatiseerimine, ühised skillid, AI meeskonnas (edasijõudnutele) |
| [Minust](minust/index.html) | Pikem lugu |
| [AI-häkid](hakid.html) | Lühikesed nipid koos promptidega |

Häkkide ja edulugude lehel saab kirja panna ka oma nipid ja lood. Need salvestuvad ainult külastaja enda brauserisse ega jõua kellegi teiseni.

## Kellele

Töötajatele, meeskonnajuhtidele ja HR-ile, kes tahavad AI-d tööl kasutada või kolleegidele tutvustada.

## Tehniliselt

Lihtne staatiline veebileht: HTML, CSS ja JavaScript, ilma ehitussammu ja serverita. Ühine kujundus ja skriptid on kaustas `assets/`. Avaldatud GitHub Pagesi kaudu. Kohalikuks vaatamiseks käivita kaustas lihtne veebiserver (nt `npx http-server`), sest vanad aadressid ja suunamised vajavad serverit.

Iga lehe sisu on otse selle HTML-failis. Külgmine sisukord on kopeeritud kõigile juhendi lehtedele. Uue teema lisamisel lisa link sisukorda igale juhendi lehele.
